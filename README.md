  <p><strong>A lightweight Android drawing and collaboration app powered by Excalidraw.</strong></p>
</div>

Calidraw brings the Excalidraw drawing experience to Android through a native Kotlin application with a WebView-based interface.

## Features

- **Drawing:** Create diagrams, sketches, and visual notes.
- **Real-time Collaboration:** Collaborate with others using shared rooms.
- **Workspace:** Organize drawings with a file-system-like interface.
- **Persistent Storage:** Automatically preserve your drawings.
- **Import & Export:** Open and save drawings using native Android file handling.
- **Dark Mode:** Comfortable drawing experience in dark environments.

## Download

Get the latest Android APK from the [Releases](https://github.com/Anxhul10/calidraw-apk/releases) page.

## Tech Stack

- Kotlin
- Android WebView
- Excalidraw
- JavaScript Interface (Android ↔ WebView)
- Excalidraw Room for collaboration
